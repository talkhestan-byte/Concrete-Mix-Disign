PWA طرح مخلوط بتن
1. فایل‌ها را در یک پوشه روی میزبان HTTPS قرار دهید (مانند GitHub Pages).
2. با Chrome اندروید آدرس سایت را باز کنید.
3. منو > Install app یا Add to Home screen.
4. پس از اولین بارگذاری موفق، برنامه آفلاین نیز قابل استفاده است.
توجه: باز کردن index.html از file:// امکان نصب استاندارد PWA و Service Worker را نمی‌دهد.
محدودیت: منحنی‌های رسمی نشریه 479 هنوز دیجیتایز نشده‌اند؛ این نسخه صرفاً محاسبات مقدماتی را انجام می‌دهد.
